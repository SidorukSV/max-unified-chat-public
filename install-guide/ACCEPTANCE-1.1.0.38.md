# Стабильное имя собеседника MAX: 1.1.0.38

## Исправление

В Едином чате главным именем диалога теперь всегда остается имя пользователя
MAX. Выбор или создание карточки пациента и запись на прием больше не заменяют
имя собеседника именем пациента.

Это важно для обращений родителей и представителей: например, диалог с
пользователем MAX «Наргиза Залунина» остается под этим именем, даже если запись
создана для пациента «Анурфиев Артем Вадимович».

Выбранная карточка показывается отдельно в подзаголовке как
`пациент: <наименование>`. Если MAX не передал имя, форма использует имя пациента
как резервное представление; если нет и пациента — текст `Пользователь MAX`.

## Обновление

Изменяется только модуль формы, структура данных не меняется. Расширение можно
загрузить заменой версии 1.1.0.37. Монопольный режим для перехода с 1.1.0.37 на
1.1.0.38 не требуется; открытые формы Единого чата после обновления нужно закрыть
и открыть заново.

Backend 1.0.8 остается без изменений.
