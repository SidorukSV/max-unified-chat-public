# Выбор отделения по callback MAX: 1.1.0.39

## Исправление

Исправлена обработка кнопок выбора отделения. MAX корректно доставлял
`message_callback` на VDS, однако при служебной записи отделения мог сработать
отказ прав объекта контакта. Вложенная отмена транзакции отменяла также
транзакцию надежного inbox, поэтому 1С не отправляла ACK и пациент не видел
результата нажатия.

`ЗакрепитьОтделение()` теперь использует уже открытую транзакцию inbox, а при
автономном вызове управляет собственной. Изменение защищенного поля контакта и
запись истории выполняются в узком привилегированном блоке после проверки бота,
контакта и доступности выбранного отделения.

Также устранена ранее скрытая ошибка метаданных: общий модуль архива чатов больше
не объявлен привилегированным целиком, что запрещено платформой для расширения.
Доступ оператора проверяется до локального повышения прав, а привилегированный
режим используется только для переноса уже проверенного диалога в архив.

## Обновление

Загрузить CFE 1.1.0.39 заменой существующего расширения. Удалять расширение или
повторно вводить настройки не нужно. Переход с 1.1.0.38 не меняет структуру данных
и не требует монопольного режима. Backend 1.0.8 остается без изменений.

После обновления запустить обмен MAX вручную либо дождаться регламентного задания.
Старые callback-события, уже помещенные локальным inbox в карантин, автоматически
не повторяются; для контрольной проверки следует запросить новую клавиатуру
командой `/department` и нажать отделение.
