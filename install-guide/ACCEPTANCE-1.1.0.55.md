# Medina 1.1.0.55 — одно подтверждение выбора отделения

После выбора отделения обработчик делал две операции: заменял сообщение
с кнопками на подтверждение через callback и отправлял тот же текст отдельным
сообщением. Отдельное сообщение дополнительно получало имя пациента.

Удалена отдельная текстовая отправка. Подтверждение остается на месте кнопок
выбора отделения; меню выбора пациента и запись выбора в истории 1С сохраняются.
Повторное нажатие не создает новую текстовую отбивку.

Проверено:

- 110 исходниковых тестов — PASS;
- структурная проверка расширения — 0 ошибок, 3 прежних предупреждения;
- сборка с CheckConfig платформой 8.3.27.2214 — PASS;
- частичная загрузка версии и модуля с UpdateDBCfg в изолированную копию — PASS;
- реальный серверный dispatcher с подписанным фиктивным контактом: назначение
  отделения, ровно одно подтверждение вида callback, отсутствие отдельного
  дублирующего текста, отсутствие нового текста/меню при повторе — PASS.
  Тест завершен rollback, сетевой отправки не было;
- обратная выгрузка CFE: версия 1.1.0.55, измененный модуль совпадает с исходником.
