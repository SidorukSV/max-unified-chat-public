# Клиентская сборка Medina: 1.1.0.51

## Исправления

- После первого успешного выбора отделения пациент получает отдельное видимое
  сообщение «Ваше обращение направлено в отделение: …». Ответ на callback также
  продолжает убирать клавиатуру из исходного сообщения.
- Повторное нажатие старой кнопки не создает дубликаты подтверждения.
- Событие `bot_started` и команда `/start` больше не закрывают и не архивируют
  активный диалог. Архивация выполняется только при явном закрытии оператором.
- Исправлена причина, по которой контакт MAX `109639803` мог снова попадать в
  архив после повторного запуска бота.

Backend не менялся: логи VDS подтвердили доставку callback до 1С, ACK события и
успешный ответ MAX HTTP 200. Исправление находится в расширении 1С.

## Обновление

Загрузить CFE `бит_МедицинаМАКС_2026_10_16.cfe` заменой существующего расширения.
Удалять расширение и повторно вводить токен, адрес VDS или настройки отделений
не нужно. Монопольный режим не требуется.

После обновления запустить обмен MAX вручную либо дождаться регламентного
задания. Для проверки отправить `/department`, выбрать отделение и дождаться
отдельного подтверждения в чате. Затем отправить обычное сообщение и убедиться,
что активный диалог не перемещается в архив.
