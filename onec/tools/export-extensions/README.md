# Выгрузка расширений

Внешняя обработка выгружает доступные в текущей информационной базе расширения в отдельные файлы `<ИмяРасширения>.cfe`.

Откройте `BUILD/ВыгрузитьРасширения.epf` в 1С, нажмите «Выгрузить все расширения» и выберите папку. Используются права текущего пользователя, без повышения привилегий. Обработка не изменяет расширения или прикладные данные базы.

## Изменения

- Понятные имена обработки, переменных и серверной функции.
- Удалены кнопка «Ни в коем случае не нажимать!», её обработчики и посторонний запрос к валютам, заявкам и авансовым отчётам.
- Удалены неиспользуемый реквизит `Каталог` и пустая ветка кода.
- Серверная функция возвращает описания файлов без передачи контекста формы; временные данные привязаны к идентификатору формы.
- Добавлено сообщение для базы без расширений и понятный заголовок выбора папки.
- Сохранены штатный механизм передачи файлов и исходный способ именования CFE. Новых зависимостей от БСП нет.

## Проверка 27.10.2026

Сборка и обратная разборка выполнены платформой 8.3.27.2214 на локальной изолированной базе УМЦ КОРП 2.1.25.61. Модуль формы после обратной разборки совпадает с исходником; в форме осталась одна команда выгрузки.

Проверки XML обработки: 10/10; формы: 14/14. BSL Language Server: 0 ошибок, 1 предупреждение `UnusedLocalMethod` для `Выгрузить` — вызов привязан к команде в XML формы и не виден анализатору отдельного BSL-файла.

Открытие формы и полный цикл сохранения через клиентский диалог не проверены: средство управления окнами было недоступно. Сборка и статический анализ не заменяют эту проверку. Рабочая база клиента не использовалась.
